# AeriS

**AeriS** es una app libre y gratuita para móvil y tablet que guía la ejecución de protocolos de laboratorio paso a paso, sin papel.

> Estado: en planificación (fase 0). Todavía no hay una versión usable.

## Qué hará

- **Mis protocolos:** crear, editar y versionar protocolos ("Nombre (V.1)", "Nombre (V.2)"…).
- **Ejecución guiada:** avanzar paso a paso con botones grandes, pensados para usar con guantes.
- **Pasos de cálculo de reactivos:** parámetros fijos del protocolo y parámetros que se introducen en cada ejecución (por ejemplo, el mastermix de una PCR).
- **Pasos de instrucciones:** texto con formato, imágenes y etiquetas para resaltar compuestos.
- **Herramientas del paso:** temporizadores que avisan con la pantalla bloqueada y alertas que no dejan avanzar sin confirmar.
- **Cuaderno de laboratorio:** cada ejecución queda guardada con fecha, valores y notas.
- **Compartir:** exportar e importar protocolos en formato JSON.

Plataformas previstas: Android e iOS. Idioma: español.

## Tecnología

- [Flutter](https://flutter.dev) y [Dart](https://dart.dev)
- Base de datos local en el dispositivo (sin cuenta y sin nube)
