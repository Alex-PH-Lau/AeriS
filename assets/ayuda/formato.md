## Botones de formato

Encima del texto de cada paso hay botones para dar formato. Selecciona el texto y pulsa el botón; pulsa otra vez para quitarlo.

- **Negrita** y *cursiva*.
- **Título**, para separar partes de un paso largo.
- **Lista** y **lista numerada**.
- **Importante**: un recuadro rojo, para avisos.
- **Imagen**: una foto del montaje, de un gel…

Con **Vista previa** ves el paso tal y como saldrá al ejecutarlo.

## Escribirlo a mano

El formato es **Markdown**, el mismo que usan muchas webs. Se puede escribir directamente:

- `**negrita**` → **negrita**
- `_cursiva_` → _cursiva_
- `## Título` al principio de la línea
- `- ` al principio de la línea para una lista, o `1. ` para una numerada
- `> ` al principio de la línea para un aviso

## Imágenes

Con el botón **Imagen** puedes hacer una foto o elegirla de la galería (en el ordenador, del explorador de archivos). AeriS la reduce para que ocupe poco y te pide un **pie de foto**.

En el texto aparece una marca como `![Montaje](imagen:img-…)`: puedes moverla a otro sitio del texto como cualquier otra línea. Al ejecutar, **toca la imagen** para verla a pantalla completa y ampliarla.

> Las imágenes viajan dentro del archivo cuando compartes un protocolo o haces una copia de seguridad.
